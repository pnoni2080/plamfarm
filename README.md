# 팜팜(Palm Farm) — 내 손 안의 농업 보드게임 (웹판)

24종의 지역 특산물 농장을 사고 밭, 가공시설, 교육농장으로 키우며 농업 지식을 익히는 부루마블식 보드게임입니다.
태블릿 한 대를 가운데 두고 2~4명(팀)이 차례대로 하도록 만들었습니다.

- 말판, 푸드카드, 레시피차트, 특수카드 그림은 원본 인쇄용 PDF에서 가져왔습니다.
- 말판의 칸을 누르면 푸드카드 앞면(작물 설명, 대표음식, 영농기술 정보)과 견학요금표를 볼 수 있습니다. 카드 그림을 누르면 크게 보입니다.
- 진행 상황은 기기 브라우저에 자동 저장됩니다. 실수로 새로고침해도 시작 화면의 **이어하기**로 돌아올 수 있습니다.
- 효과음은 Kenney의 [Impact Sounds](https://kenney.nl/assets/impact-sounds)(CC0)에서 골라 mp3로 변환했습니다. 화면의 **소리 켜짐/꺼짐** 버튼으로 끌 수 있습니다.
- 규칙과, 매뉴얼에 없어서 따로 정한 부분은 [RULES.md](RULES.md)에 정리했습니다.

**바로 하기: https://pnoni2080.github.io/plamfarm/**

## 실행 방법
빌드 과정이 없는 정적 웹페이지입니다.

- **GitHub Pages**: 저장소 Settings → Pages에서 `main` 브랜치의 루트(`/`)를 선택하면 위 주소로 열립니다. `main`에 올린 변경은 1~2분 뒤 자동으로 반영됩니다.
- **내 컴퓨터에서**: 폴더에서 아래 명령을 실행한 뒤 `http://localhost:8000`에 접속합니다.

```bash
python3 -m http.server 8000
```

태블릿은 **가로 화면**을 권장합니다. 세로 화면에서는 말판 아래에 패널이 표시됩니다.

## 파일 구성
- `index.html` — 화면 구조
- `css/style.css` — 디자인
- `js/data.js` — 카드 데이터(가격, 견학요금, 레시피, 찬스카드 등)
- `js/game.js` — 게임 진행 규칙과 화면 처리
- `js/sound.js` — 효과음(장면별 소리 파일과 음량)
- `assets/` — 말판, 카드, 아이콘 이미지
